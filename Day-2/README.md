# Day 2 – Salesforce Developer Bridge Program

## Overview

The second day of the Salesforce Developer Bridge Program focused on advanced Apex concepts and Lightning Web Components. The practical assignments emphasized writing optimized and scalable Apex code while understanding Salesforce governor limits and asynchronous processing. Additionally, I implemented communication between Lightning Web Components to build more interactive Salesforce applications. All tasks were developed and tested using the Salesforce Platform, Apex, Lightning Web Components (LWC), and VS Code.

## Tasks Completed

### 1. Apex Collections
Implemented different Apex collection types, including **List**, **Set**, and **Map**, to store, retrieve, and manage data efficiently. Executed the code using Execute Anonymous and verified the results through Debug Logs.

### 2. Governor Limits and Bulkification
Learned about Salesforce Governor Limits by implementing a trigger that exceeded the SOQL query limit and then optimized it using bulkification techniques. This improved performance and ensured the trigger could process multiple records efficiently.

### 3. Asynchronous Apex
Developed an **@future** Apex method to perform operations asynchronously. Executed the method and verified successful execution through the Apex Jobs page.

### 4. Lightning Web Component Communication
Implemented communication between Parent and Child Lightning Web Components using **@api properties** and **Custom Events**, allowing data to be exchanged between components dynamically.

## Learning Outcomes

- Understood the usage of Apex Collections (List, Set, and Map).
- Learned Salesforce Governor Limits and Bulkification best practices.
- Implemented asynchronous processing using **@future** methods.
- Developed interactive Lightning Web Components with Parent-Child communication.
- Improved knowledge of writing optimized and scalable Apex code.
