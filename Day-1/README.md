# Day 1 – Salesforce Developer Bridge Program

## Overview

The first day of the Salesforce Developer Bridge Program focused on understanding the core concepts of Salesforce development through practical implementation. The assignments were based on a **Hospital OPD Management System**, where I designed a custom data model and implemented various Salesforce features using both declarative and programmatic approaches. Throughout the day, I worked with Salesforce Platform tools such as Schema Builder, Apex, SOQL, Lightning Web Components (LWC), and VS Code to build and test different functionalities.

## Tasks Completed

### 1. Hospital OPD Data Model
Designed a custom data model using **Schema Builder** by creating the Patient, Doctor, Appointment, and Prescription objects along with their required fields and relationships.

### 2. Apex Programming
Practiced Apex programming by writing and executing Apex code using **Execute Anonymous** in the Developer Console and verified the output through Debug Logs.

### 3. SOQL Queries
Executed multiple **SOQL** queries to retrieve, filter, sort, aggregate, and analyze records from custom objects, gaining hands-on experience with Salesforce data retrieval.

### 4. Apex Trigger
Developed an **Apex Trigger** with a separate Handler Class to implement business logic such as duplicate appointment validation and automatic record updates while following Salesforce best practices.

### 5. Lightning Web Component (LWC)
Built and deployed a **Lightning Web Component** using **VS Code** to display patient information dynamically on the Salesforce Home Page.

## Learning Outcomes

- Understood Salesforce custom objects, fields, and relationships.
- Gained practical experience with Apex programming and debugging.
- Learned different types of SOQL queries for data retrieval.
- Implemented Apex Triggers using the Trigger Handler pattern.
- Developed and deployed a Lightning Web Component using VS Code.
- Improved practical knowledge of Salesforce application development.
