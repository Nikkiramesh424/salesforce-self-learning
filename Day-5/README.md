# 🏥 Day 5 – Hospital OPD Management System

## 📌 Overview

This project was developed as part of **Day 5 – Engineering Sprint: Building Complete Business Transactions with SOQL, DML, and Apex**.

The Placement Management System scenario was adapted into a **Hospital OPD Management System** using Salesforce.

---

## 🎯 Objectives

- Retrieve Patient information using SOQL.
- Retrieve Doctor information using SOQL.
- Prevent duplicate appointments.
- Create Appointment records using DML.
- Update Appointment Status.
- Complete an end-to-end business transaction.

## 📋 Business Flow

```text
Patient Request
      │
      ▼
Retrieve Patient
      │
      ▼
Retrieve Doctor
      │
      ▼
Validate Appointment
      │
      ▼
Check Duplicate Appointment
      │
      ▼
Create Appointment
      │
      ▼
Update Appointment Status
      │
      ▼

```
