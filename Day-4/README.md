# Day 4 – Lightning Web Components (LWC)

## Overview

Day 4 focused on building the first user interface using **Lightning Web Components (LWC)**. The objective was to understand the role of LWC in Salesforce, create reusable UI components, implement data binding, handle user interactions using JavaScript, and deploy components to a Lightning Page.

---

## What is Lightning Web Components (LWC)?

Lightning Web Components (LWC) is Salesforce's modern user interface framework built on standard web technologies such as **HTML, JavaScript, and CSS**. It enables developers to build fast, reusable, and maintainable components that interact with Salesforce data and business logic. :contentReference[oaicite:1]{index=1}

## What Did I Build?

During this session, I completed the following practical activities:

- Created my first Lightning Web Component (`placementHome`).
- Displayed student information using JavaScript variables.
- Implemented data binding to dynamically update values.
- Added buttons to display welcome messages and update application status.
- Developed the first screen of a Placement Management System using LWC.
- Deployed the component to a Lightning App Page.

---

## Lightning Web Component Structure

### HTML File
Responsible for designing the user interface, including text, buttons, images, and page layout.

### JavaScript File
Contains component logic, variables, events, and button click handling.

### Meta XML File
Makes the component available in Lightning App Builder and defines where it can be deployed.
